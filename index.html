Save straight to a OneDrive folder

One-time setup in the Shortcuts app. After this, Export → your shortcut saves the photos without asking where.

  1. Make sure the OneDrive app is installed and signed in, and the target folder exists.
  2. Open Shortcuts → tap + to create a new shortcut. Name it Save to Work Folder.
  3. Tap the ⓘ (Details) button → turn on Show in Share Sheet. Under Share Sheet Types, keep only Images.
  4. Add the action Save File. It should read “Save Shortcut Input”.
  5. Expand the action: turn off “Ask Where to Save”. Tap the destination folder and pick OneDrive → your work folder.
  6. Tap Done.

Test it once with one photo. If OneDrive cannot be picked as the destination, use “Save to Files” in the share sheet instead.

Photos live only inside this app (not in iCloud). Export before deleting the app from the Home Screen.
